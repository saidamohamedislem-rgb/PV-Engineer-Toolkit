# Projektübersicht – PV Engineer Toolkit

## Ziel des Projekts

Dieses Projekt zeigt einen strukturierten technischen Workflow zur Auslegung einer industriellen Photovoltaikanlage mit PowerShell.

Der Fokus liegt auf:

- PV-Modulberechnung
- String-Auslegung
- Wechselrichter-Auswahl
- automatischer technischer Dokumentation
- sauberem Git/GitHub-Workflow

## Warum dieses Projekt?

Nach meinem Vorstellungsgespräch bei Energietechnik West wollte ich meine Kenntnisse im Bereich Photovoltaikplanung, DC-Planung und Automatisierung gezielt vertiefen.

Das Projekt verbindet Elektrotechnik, Photovoltaik, Dokumentation und Automatisierung.

## Aktueller Funktionsumfang

- Modul-Datenbank als JSON
- Wechselrichter-Datenbank als JSON
- Berechnung der notwendigen Modulanzahl
- Prüfung der maximalen Stringspannung
- Vorschlag einer String-Aufteilung
- Auswahl geeigneter Wechselrichter
- Erstellung eines Projektberichts

## Technischer Schwerpunkt

Die DC-Planung prüft insbesondere:

- installierte DC-Leistung
- Modulanzahl
- Leerlaufspannung pro String
- Stringanzahl
- Wechselrichter-Eingänge
- DC/AC-Verhältnis

## Ergebnis

Das Toolkit erstellt automatisch technische Berichte im Ordner `Reports`.
